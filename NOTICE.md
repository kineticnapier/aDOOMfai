# Notices

ADOOMFAI hosts a DOOM-compatible engine inside A Dance of Fire and Ice and renders
the resulting 320x200 framebuffer to a Unity/ADOFAI decoration.

The native build fetches and links against `ozkl/doomgeneric`, which contains
DOOM-derived GPL source code. The build script pins the upstream revision.

No commercial DOOM IWAD, art, maps, music, sound effects, or other proprietary game
data is included in this repository.

Users must provide their own compatible IWAD, or use freely distributable replacement
game data such as Freedoom.

ADOOMFAI is an unofficial fan/technical project and is not affiliated with id Software,
Bethesda, ZeniMax, 7th Beat Games, or the doomgeneric maintainers.
